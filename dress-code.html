Dress Code

Para você aproveitar a festa com conforto e estilo

Como vamos passar o dia todo juntos, preparamos algumas dicas para todo mundo curtir ao máximo e bem confortável:

👗

O Traje

Venha com roupa bem leve e confortável (shorts, bermudas, vestidos frescos, camisetas). O clima é de total descontração!

🏊

Piscina

A piscina está liberada! Não esqueça de trazer sua roupa de banho e uma toalha.

👟

Calçados

Vá de chinelo, rasteirinha ou tênis. Evite salto alto, pois o chão é de grama e terra.

👚

Muda de roupa

Como o evento é longo, vale a pena trazer uma troca de roupa seca para se vestir após sair da piscina.

🧥

Para o fim do dia

Como o sítio costuma esfriar quando o sol se põe, traga um casaco leve ou moletom para garantir o conforto.

☀️

Não esqueça

Protetor solar, óculos de sol e repelente.

✦

Venha pronto para relaxar e se divertir! Esperamos você!
